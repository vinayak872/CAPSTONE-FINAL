Sequence Diagram
sequenceDiagram autonumber participant Client as User / Client HTTP Traffic participant Gateway as API Gateway (cloud05-active-service) participant Canary as Canary Pod (Candidate v2.0) participant Stable as Stable Pods (Active v1.0.1) participant Prom as Prometheus Server (Port 9090) participant Analysis as Argo Rollouts AnalysisRun participant Rollout as Argo Rollouts Controller Client->>Gateway: Incoming HTTP Requests Gateway->>Canary: Route 10% Canary Traffic Gateway->>Stable: Route 90% Stable Traffic Canary-->>Gateway: HTTP Responses (With Errors if Defective) Prom->>Canary: Scrape /metrics (every 5 seconds) Rollout->>Analysis: Instantiate AnalysisRun for Current Step Analysis->>Prom: Query PromQL: Error Rate & Success Rate alt Scenario A: Healthy Candidate (Error Rate <= 5%) Prom-->>Analysis: Error Rate = 0.0% (PASS) Analysis-->>Rollout: Phase: Successful (3 consecutive passes) Rollout->>Gateway: Advance Traffic Weight (25% -> 50% -> 100%) Note over Rollout,Gateway: Candidate Successfully Promoted to Active Stable else Scenario B: Defective Candidate (Error Rate > 5%) Prom-->>Analysis: Error Rate = 18.2% (BREACH DETECTED) Analysis-->>Rollout: Phase: Failed (Failure limit reached) Rollout->>Canary: Abort Rollout (Scale Canary Pods to 0) Rollout->>Gateway: Immediate Cutover: 100% Traffic to Stable Release Note over Rollout,Stable: Autonomous Circuit Breaker Rollback (MTTR = 0.75s) end
Sequence Explanation: Compares normal operation (Scenario A: 3 consecutive passes promote candidate) with fault injection (Scenario B: error rate exceeds 5%, AnalysisRun fails, Rollouts controller scales canary to 0, and restores 100% traffic to stable release).

3. Progressive Delivery State Machine

State Machine
stateDiagram-v2 [*] --> STABLE: System Initialized (v1.0.1 Active) STABLE --> DEPLOYING: Candidate Deployment Triggered (e.g. v2.0) state DEPLOYING { [*] --> Canary10: Step 1 (10% Canary / 90% Stable) Canary10 --> HealthProbe1: Prometheus AnalysisRun Probe HealthProbe1 --> Canary25: Pass (Error Rate <= 5%) Canary25 --> HealthProbe2: Prometheus AnalysisRun Probe HealthProbe2 --> Canary50: Pass (Error Rate <= 5%) Canary50 --> Canary100: Pass (Error Rate <= 5%) } DEPLOYING --> STABLE: 100% Promoted (Candidate becomes new Stable) DEPLOYING --> ROLLED_BACK: Health Threshold Breached (Error Rate > 5%) state ROLLED_BACK { [*] --> AbortCanary: Abort Rollout & Terminate Candidate Pods AbortCanary --> RestoreStable: Route 100% Traffic to Previous Stable } ROLLED_BACK --> STABLE: State Machine Reset or New Valid Deployment
State Machine Explanation: In-memory and cluster states transition from STABLE to DEPLOYING, progressing through fractional canary weights until either STABLE (promoted) or ROLLED_BACK (aborted due to threshold breach).
